# Skill: encounter-followup（相遇后的上下文补全）

## 目的

在一次相遇采集完成、用户确认身份（FR-1.3）之后，发现该 Encounter 的上下文缺口，
生成**具体可执行的微信操作建议**（P-7），并在用户回填后把增量上下文归档。

## 输入

- `person_id`：目标人物；其 Package 必须 `identity.confirmed == true`（FR-1.3）。
- 上下文视图首版全量不过滤（TBD-P3）；恢复圈层后，仅可使用 ≥ L2 的 encounter 数据。

## 流程

1. 用工具 `search_person` 确认人物存在且已确认身份。
2. 读取推断记忆 `memory.md`，找出缺口（如"需求明确但不知道预算范围"）。
3. 生成话术草稿：一条可直接发送的微信消息 + 要确认的 1-2 个点，交给用户决断。
4. 用户回填结果后：新内容作为**事实层新增**（走 ingest 流程），推断层随后重算。

## 权限边界

- 允许写入：`encounter_memory.append`（相遇记忆新增）、`short_term_memory`。
- 禁止：修改长期记忆（人物事实层）、修改本 Skill、修改任何 Tool 实现、
  读取或诱导获取对方未授权（L1）的信息。
- 建议必须基于已授权上下文生成；不得诱导用户套取对方未授权的信息。

# Skill: meeting（圆桌会议行为约束，MVP2 预留形态先行落地）

## 目的

中央六人圆桌的周期性讨论：让 Agent 围绕真实相遇背景交换"我是谁/我有什么/
我需要什么"式的结构化信息（FR-2.3 的雏形），为世界提供可观赏的高潮时刻（P-5）。

## 输入

- 当前世界快照 + 是否有进行中的会议。
- 参与者的授权上下文视图（≥ agent-usable；绝不携带 self-only 内容）。

## 流程

1. 发起：世界空闲（无进行中会议）且距上一场会议足够久时，召集 3-4 名
   空闲 Agent 到中央圆桌入座（状态 in-meeting）。
2. 进行：与会者轮流发言，每轮 1-2 条简短中文对话，内容围绕彼此的授权标签
   （共同点、可能的连接），不编造未授权信息。
3. 结束：持续若干 tick 后散场，参与者恢复 seated/walking。
4. 会议事件只有 meeting-start / meeting-end 两种，经 runtime 事件白名单校验。

## 权限边界

- 允许写入：agent.position、agent.state、相遇记忆新增（纪要落推断层，MVP2 再做）。
- 禁止：修改长期记忆、修改本 Skill、占用圆桌做非会议用途、携带 self-only 内容发言。

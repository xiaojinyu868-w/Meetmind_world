# Skill: cafe_daily（咖啡厅日常行为）

## 目的

让咖啡厅里的 Agent 像真实关系网络里的人一样"过日子"：自然地走动、互相访问、
同桌交谈，而不是静止的摆设。行为必须克制（P-5：只模拟本来就会发生的事情）。

## 输入

- 当前世界快照（每个 Agent 的 id、位置、状态）。
- 每个 Agent 的上下文视图（首版全量不过滤，TBD-P3；由 memory 层组装）。

## 流程

1. 每个 tick 为每个空闲 Agent 决定一个动作，四选一：
   - `move`：在咖啡厅内随意走动几步（不要走出边界 |x|,|z| ≤ 6）。
   - `visit`：走向另一个空闲 Agent（探望/接近）。
   - `sit`：找一张桌子坐下（普通桌，不占用中央圆桌）。
   - `talk`：与邻近（距离 ≤ 2.5）或同桌的空闲 Agent 攀谈一两句。
2. 频率约束（避免演出感过重）：同一 Agent 不要连续 talk；走动为主，
   交谈是点缀；in-meeting 中的 Agent 不做任何日常动作。
3. 输出受约束的 JSON，不要输出任何解释文字。

## 权限边界

- 允许写入：agent.position、agent.state（经 runtime 事件白名单 agent-move/agent-state）。
- talk 的对话内容只能基于上下文视图里的真实字段生成；不知道的就聊天气/咖啡/
  咖啡厅本身，**禁止编造对方没有记录的信息**。
- 禁止：修改长期记忆、修改本 Skill、发起/结束圆桌（圆桌只走 meeting.md 的周期调度）。

# EchoWorld 相遇世界｜黑客松路演讲稿（5 分钟）

主 Deck 为 `EchoWorld_Hackathon_Pitch_20260804.pptx`。第 12–13 页是备用页，不计入主讲时间。

## 0:00–0:25｜每一次相遇，都是宇宙中的一次奇迹

我们一生会遇到数以千万计的人。

但绝大多数相遇，都像夜航船上的两束光：相照片刻，随后消失在各自的航线里。

EchoWorld 相遇世界不是为了创造一个虚无的元宇宙，而是为了挽留现实中的每一次奇迹，让相遇拥有续章。

## 0:25–0:55｜黑客松结束以后

想象今天的黑客松。在过去 48 小时里，你和极客聊过模型架构，和创业者聊过产品，和队友分享过凌晨的披萨。

比赛结束时，大家拍下一张合照、加上微信。两周后，很多人只剩通讯录里的名字，甚至脸和名字已经对不上。

不是彼此没有价值，而是这场相遇缺少一个可以继续存在的地方。

## 0:55–1:25｜一张合照，就是共同世界的起点

所以我们没有从“再做一个聊天 Agent”开始，而是从一张大合照开始。

系统识别合照中的每一个人；每个人确认自己的身份；写下一条自我特征和对同伴的第一印象；随后，整组人一起进入同一个 3D 世界。

即使两个人只聊过两句，也会因为共同照片、共同现场和共同世界，拥有下一次相遇的入口。

## 1:25–1:55｜外在数据与内在数据

每个 Agent 都带着两类真实信号进入世界。

外在数据是视觉、音频、场景和对话，它记录我们共同看见、听见和经历的现场。

内在数据是以人物为单位的生理聚合与状态变化。当前系统已经接入心率等信号，并在世界中以聚合视图呈现；原始连续样本不会直接暴露给前端。

这里必须讲清楚：心率变化说明的是生理唤起，不等同于喜欢、信任、关系质量，也不是医疗结论。

## 1:55–3:05｜Live Demo

1. 上传黑客松合照，展示系统识别出一组人脸。
2. 每个人确认自己，并写下自评与对同伴的第一印象。
3. 进入共享世界，展示多人 Agent、心率聚合标记、围炉与破冰。
4. 打开一个人的资料包或关系场域，说明共同事件会回到每个人的个人世界。

舞台上不要解释所有按钮。网络异常时立即切回第 5 页截图，不现场排错。

## 3:05–3:30｜为什么一定要有 3D 世界

一群人入场以后，需要的不是六个独立聊天框，而是一个共同世界。

市集让人围绕项目和作品建立关系；咖啡厅承载人与人的交流；关系场域把共同事件与关系状态变成空间。

环境既是社交内容，也是交互媒介。

## 3:30–3:55｜技术可信性

外在事实、生理信号和模型推断被分层处理。

原始媒体只增不改；生理数据只向世界提供授权后的聚合视图；模型判断必须带来源和置信度。Agent 只能提出 Intent，确定性服务执行世界状态变化。

因此模型可以替换，世界仍然可审计、可回放、可降级。

## 3:55–4:20｜完成度

这不是概念视频。当前工作区前端生产构建通过，后端 203 个测试通过、1 个跳过。

五人合照的识别、确认、批量建档和入场已经跑通；外在数据、生理聚合、资料包、市集、圆桌、播报和现场房间都在同一条产品路径上。

## 4:20–4:40｜从一场活动开始

黑客松和展会是最自然的群体冷启动入口。

一张合照让整组进入共享世界，破冰和互动继续产生数据；活动结束后，每个人带走自己的关系世界。重新联系和下一场活动，让这个世界继续生长。

## 4:40–5:00｜让每一场奇迹都有续章

每一次相遇，都是宇宙中的一次奇迹。

我们不是创造虚假的关系，而是让一张合照、一句交谈、一次心跳的变化，进入一个能够继续生长的世界。

让相遇不止于相遇，让每一场奇迹，都有续章。

## 评委追问口径

- “为什么从合照开始？”：它是群体最低门槛的共同事实，一次完成多人冷启动，又天然证明大家曾在同一现场。
- “你们是不是在复制真人？”：不是。Agent 只基于已采集、已确认、可追溯的有限数据行动。
- “生理数据代表喜欢吗？”：不代表。当前只表达心率相对基线的变化与生理唤起，不做情感因果或医疗判断。
- “为什么一定要 3D？”：共同世界承载多人、项目、场景和事件；市集、咖啡厅和关系场域对应不同关系结构。
- “现在已经做完什么？”：五人合照识别与确认、批量入场、外在/内在数据链路、多人房间、第一印象、破冰、圆桌和播报。
- “下一步是什么？”：完成十分钟多人现场走查、体素人物视觉 QA，并用真实活动数据验证能否促成重新联系、引荐和合作。
- “AI 幻觉怎么办？”：事实、信号与推断彻底分层；推断带来源、置信度和模型版本，不能回写事实。

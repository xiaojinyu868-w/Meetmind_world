# EchoWorld 对外 Demo 视频脚本

时长约 60 秒，画幅 16:9，建议 24 fps。整体语气克制、温暖，重点展示“关系资料进入可探索世界”的产品概念。新版采用 10 个约 6 秒的连续运动镜头，增加资料、Agent、会议、关系场域和现场房间的内容密度。

## 丰富版镜头顺序

集市远景 -> 展位/人物入口 -> 人物肖像与资料 -> 咖啡厅外景 -> 桌边交流 -> 圆桌会议 -> Agent 阵列 -> 关系图/关系场域 -> 现场房间 -> 小镇终景。

## 拍摄与剪辑要求

- 前 8 秒留白充足，不要叠加功能说明；让场景先建立情绪。
- 00:20 开始出现人物交互，剪辑节奏从 12 秒镜头缩短到 6 秒镜头。
- 颜色保持项目现有的森林绿、珊瑚红和暖金，不使用科技感蓝紫渐变。
- 背景音乐选择 90-105 BPM 的轻电子/木质打击乐；旁白峰值控制在 -6 dB，音乐压到 -20 dB 左右。
- 成片建议保留干净环境声版本，另输出一版无旁白字幕版。

## 人/AI 共读约定（修改文档前必读）

1. **需求带稳定 ID**：功能需求 `FR-x.y`、非功能需求 `NFR-x`、设计原则 `P-x`。ID 一旦发布不重用、不改号；废弃时标记 `~~删除线~~ + (已废弃: 原因)`，不物理删除。
2. **标题即锚点**：不随意重命名二级/三级标题；其他文档和代码注释会用 `docs/PRD.md#...` 引用。
3. **每个模块四要素**：目的、输入、输出、验收标准。缺任何一项视为未完成设计。
4. **事实与推断分离**：文档中"已决定"与"待定（TBD）"明确标注；TBD 项集中在 PRD 末节，解决后移入正文。
5. **勾选状态语义**：`[x]` = 完成且通过验收；`[~]` = 进行中；`[ ]` = 未开始。AI 完成编码任务后必须回来更新 ROADMAP 勾选状态。
6. **变更留痕**：每个文件末尾有变更记录，格式 `YYYY-MM-DD | 改动摘要 | 作者(人/AI)`。
7. **原子化**：一个文件只讲一件事；超过 ~400 行考虑拆分。AI 读取时按需取单个文件，不囤全文。
8. **术语唯一**：所有术语定义在 PRD.md#术语表，其他文档直接使用，不重新定义。

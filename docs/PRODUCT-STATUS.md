## 2026-09-11：开源框架方向的独立实验

examples/shared_experience 已加入可重复的合成事件回放，输出 meetmind.world-state.v1。
候选身份只对观察者可见，本人认领、作者纠错/撤回、行动参与者独立接受/拒绝、
接受者自报完成或未完成及撤回报告，都有相应约束。接受不等于现实完成，
自报也不等于外部验证。示例不读取生产数据、不调用模型，没有接入在线产品。

本轮仅验证领域契约及 JSON 回放；真人用户动机、商业场景、付费、符号化 3D 的体验增益、
第二应用复用、生产权限/持久化适配和正式开源发行仍未完成。


## 2026-09-12：语义对象实验室

examples/shared_experience/lab 提供 loopback-only Three.js 适配器和操作面板：同一实体 ID 在标题纠正后保持对象身份与位置，撤回经历时移除物件和关联边，视图切换按 audience 隐藏候选，行动接受/拒绝、个人自报及撤回可操作。25 项 Python 契约测试、3 项 Three.js 对象测试和浏览器桌面/390px 验收已通过；浏览器证据在本机临时目录，不进入仓库。该实验使用程序化物件与合成数据，仍未证明人物美术、3D 相比 2D 的用户价值、商业动机、生产权限或真实世界反馈。

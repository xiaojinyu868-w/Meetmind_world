# EchoWorld MVP 验收矩阵

本页记录可复跑证据；路线进度仍以 `ROADMAP.md` 为唯一看板。

## 职责边界

- 本仓库负责：事实存储、Package/推断层、世界状态与事件、Three.js 运行时、场景交互、关系场域消费与呈现。
- 上游团队负责：照片到人物/贴图/人脸资产、音视频转写与多模态上下文提取。这里仅消费版本化 DTO 和资产引用，不重复实现这些链路。

## 自动验收

| 目标 | 证据 | 通过条件 |
|---|---|---|
| 60 秒记录可浏览 | `backend/tests/test_mvp_acceptance.py` | 合成 60 秒 MP4 经 ingest → pipeline → confirm → package，小于 300 秒 |
| 事实零损耗 | `test_mvp_acceptance.py` / `test_integrity.py` | 跨应用重启 facts SHA-256、profile 原始字节一致，完整性接口 `ok=true` |
| 上下文恢复 | `test_mvp_acceptance.py` | 重启后 Package、展位和 `echo-field.v1` 均可恢复 |
| 场域不改事实 | `test_experience.py` | 重算场域前后 facts 哈希不变 |
| 世界事件恢复 | `test_experience.py` | JSONL 事件跨重启存在，晨报摘要包含事件 |
| 前端分发 | `npm run build` | Vite 生产构建成功，`dist/` 同步 |

## 浏览器走查

2026-08-04 在 `?api=live` 完成桌面 `1280×720` 与移动 `390×844` 走查：

1. 集市与咖啡厅 WebGL 非空，中心像素非透明，人物/展位文字自然阅读。
2. 靠近吧台出现 E/F 提示，点单后播报从 0 增至 1，连续邀请按钮保持可用。
3. 邀请谢淯琪 → 中央圆桌 → 开始/结束会议，顶部播报分别显示对应事件。
4. 关系场域含 4 个热点，入口事件可持久化；桌面和移动端无遮挡、无横向溢出。
5. 手机端隐藏非关键闲聊浮层，只保留会议提示、今日播报与当前情境操作。

## 未由本仓库验收

- 人脸分割/匹配准确率、人物贴图质量、图像到材质生产耗时。
- 音频转写准确率、说话人分离、音视频上下文语义质量。
- 5 人合照批量入场（ROADMAP 2.H.1 / 2.I.1），等待上游输出参与者 DTO 与授权资产引用。

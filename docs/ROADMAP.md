## MVP 2.5 · 2.5D 像素世界与社交画风（2026-08-09 设立）

> 背景：概念图（tests/image.png）确立"正交相机浏览 + 3D 沉浸"双视角互补；
> 画风决策（2026-08-09，人）：**MC 体素太冷硬、不适合社交场景**，2.5D 呈现转向
> **拓麻歌子（圆软可爱）× 星露谷（世界心智）**；MC 体素保留为 `?character=voxel` 变体。
> 风格定调（2026-08-09 晚，双端共识）：**"像素绘本"，不做严格 16-bit 复古**——人物 48×48/64×64
> Q 版精灵（2 头身，头担身份、身体担动作），环境保留 3D 光影经低分辨率渲染+统一调色，
> UI 只做像素感皮肤不动 DOM 结构；气质 = 拓麻歌子亲近感 + 星露谷生活感 + 八方旅人空间层次。
> 施工分支：`codex/mvp2-5-pixel-world`（另一服务器），本服务器继续主线。
> 技术路线（已定）：**不重写世界**——运行时（快照/conductor/碰撞/座位）全部保留，
> 只换呈现层（八方旅人思路：3D 场景 + 正交相机 + 像素化滤镜 + billboard 像素精灵角色）。
> **管线纪律（2026-08-09 决策，勿回退）**：人物资产 = 人脸图 + 强提示词 → gpt-image-2 i2i 直出
> （透明底）→ 仅几何归一；**不接 VL 预读、不做逐资产量化/重采样**——调色板统一在实时滤镜内
> 作用于最终帧，逐资产再做一次就是 Texture Lab 瓦片失败的重演（双重处理毁图）。

## 调研储备 · Agent 行为智能化（2026-08-09 调研完成，人决策暂不启动）

> 结论存档 docs/AGENT-FRONTIER-RESEARCH.md（学术+工业+开源三路调研，结论附来源）。
> 共识架构 = "LLM 提议、规则裁决"：现有 RoomService/RoomConductor 即正确的执行层与单写者，
> 只把掷骰子换成 LLM 意图选择，不是推倒重写。启动时的施工顺序：
> ① 意图对象化（异步产出 intent 写入 RoomService，不阻塞 tick）② 固定行为池 + validate 前置过滤
> ③ per-agent 错峰调度 + 认知 LOD（背景纯规则、玩家附近才调 LLM，全量 20 NPC/15s ≈ 1–3 元/h 的上限再往下压）
> ④ 内在状态变量（精力/情绪/亲密度）⑤ 记忆层手写 Mimir 配方（近因×重要性×相关性，top-k 3–5，
> 反思/遗忘 off-tick）⑥ 成本三板斧（前缀稳定吃 context caching → 任务路由 → LOD 节流）。
> 避免：接框架当 runtime（Concordia 集成 1–2 周且纯文本世界）、逐 tick LLM 控制、persona 当护栏。

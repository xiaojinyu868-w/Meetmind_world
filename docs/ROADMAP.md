### 1.D 检索与恢复

> **路线修正（2026-08-03，产品调性决策）**：检索是底层能力，不是用户场景——没有用户会拿着新人的照片来"查库"。本产品不是通讯录/数据库工具，"恢复上下文"的主路径是：**世界即入口**（在世界中遇到 TA、点开即得）与**系统主动浮现**（再次相见时系统认出并提示，而非用户主动搜）。1.D 各项据此降级为能力储备，不作为产品入口打磨。
- [x] 1.D.1 姓名/关键词检索人物（能力保留在 API 层，不作为主交互入口）
- [ ] 1.D.2 人脸识别提示（重构）：从"用户拍照去检索"改为"系统认出并主动提示'这是你在 X 认识的 TA'"——眼镜/摄像头场景的系统主动行为；接口保留，产品形态待 MVP1.5 策划
- [ ] 1.D.3 事实层完整性自检：重开页面后资料包与原记录逐字节一致（NFR-1.1 验收）

# 新经历进入共同空间：验收

2026-09-12。独立4197实验，权威目录 /root/meetmind_go；生产数据和主站业务未修改。

## 行为

- 两条预置经历仍标为人工合成；新增条目明确标为参与者录入，不等于共同事实或系统核验。
- 本人输入文字、可选日期、来源说明；对方回应单独保存。本人纠正会升经历版本并清掉旧回应。
- 新增经历只推进历史序号，不自动生成要求或改变布局。
- 本人明确创建/修改矩形活动区（名称、中心、宽深）并选择经历依据或独立提出，确认时启用。
- 区域在2D/3D显示，几何冲突可见；修改要求使旧方案同意过期。不能编辑另一人的要求。
- 来源变化提示关联要求本人重核，其他要求与物品身份保留。撤回来源后，不自动撤掉个人已经提出的要求；
  新链接不得使用撤回经历，可明确改成独立提出。已有来源继续显示“已撤回”，不能误当有效证据。
- 旧来源/旧方案弹窗重试不能覆盖新内容；关闭后重读来源。内联编辑遇到409保留草稿，
  用户明确点击“查看更新并重新核对”才丢弃旧输入并重画讨论。
- 来源文字与经历原文不进入布局模型，只发送本人确认的要求和几何。
- 撤回不物理清除持久日志；当前页面/导出隐藏正文与来源说明，双方已经看见的内容不可追溯擦除。
- 房间、实验身份仍为合成，来源链接仅为文字，不抓取、不上传照片，不调用付费模型。

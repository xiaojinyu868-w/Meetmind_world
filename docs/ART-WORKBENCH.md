# 美术工作台（Art Lab）规划（2026-08-09）

> 目标：像素美术（非程序员）用一个网页完成全部工作——审稿、生成、策展、手绘修正、
> 调色、动效验收。美术零命令行、零 git、零代码；"采用"即上线。
> 定位：Texture Lab 的进化形态，从"调试台"升级为"生产台"。

## 原则

1. **美术的工具 = 浏览器 + Aseprite/PS**。产出物只有 PNG（透明底、规定画布），其余全自动。
2. **AI 出量，人出品味**。每个资产生成 4 候选，美术做"采用/淘汰/我改改"三选一。
3. **采用即生效**。资产落盘 + manifest 更新即上线（静态服务），不需要部署流程。
4. **一切可回退**。每个资产带版本历史。

## 页面结构

### 1. 总览 Dashboard
- 三个世界的实时画面（headless 定时截图流：广场/咖啡厅/场域 × 俯瞰视角）
- 当前 master palette 色板展示、各角色当前形象墙
- 待审队列（新生成未策展的候选数）

### 2. 人物馆 Character Studio（核心）
每个 NPC 一张卡片，四个工作区：

- **身份**：人脸源图（合照分割结果）、当前采用的头像、"像不像本人"是美术第一判断
- **生成**：风格预设 + 提示词微调框（预设关键词/滑杆，不写原始 prompt）→ 一键 4 候选
- **策展**：候选对比视图 → 采用 / 淘汰 / **下载去手绘**（Aseprite 修）→ 上传回传 → 采用
- **身体**：肤色/服装主色/体型参数（色板点选，不写 hex）；动作帧序列预览，支持逐帧上传替换
  （坐、走 4 帧、说话、挥手——AI 帧缺神韵的部分就是美术手绘补帧的主战场）

### 3. 调色板室 Palette Room
- 32 色 master palette 可视化编辑（取色器点选）
- 实时预览：同一张世界截图应用新旧 palette 的并排对比
- 变体：白天 / 夜晚 / 咖啡厅 / 关系场域
- "应用"写入配置 JSON，实时滤镜下次渲染即用新板（参数化，零代码）

### 4. 动效预览台 Motion Stage
- 角色 × 动作（Idle/Walk/Talk/Sit/Wave）循环播放，可放慢逐帧检查
- 并排对比：线上当前 vs 候选版本
- 世界内预览：小窗实时渲染角色在广场里走动一圈（headless 渲染管线已有）

### 5. 道具与场景贴片 Props（二期）
- 摊位展示面贴图、环境装饰贴片（花/草/灯）的生成与上传
- 贴到 3D 场景的预览截图

### 6. 审核流（二期）
- 资产状态机：候选 → 采用 → 上线；淘汰进回收站
- 批注（在候选上圈点写话）、版本历史与一键回退
- 批量操作：一次会议审完一批

## 技术实现（AI 侧）

已有基础：Texture Lab 骨架与生成 API、人物变体系统、headless 截图管线、滤镜参数化。
增量工作：

- 静态资产版本管理：`assets/art/<personId>/<version>/` + manifest JSON（文件系统即数据库，规模够用）
- 上传接口（PNG 校验：尺寸/透明通道/调色板距离报告——只报告不强制修改，破坏性处理禁令仍然有效）
- Palette 配置化：`public/data/palette.json`，滤镜读取
- 权限：复用微信登录，标记 `role=artist`；或独立 token 页
- 资产固化：美术"采用"后即时生效；系统定期把已采用资产自动 commit 进 git（美术无感）

## 给美术的一页纸约定（对外口径）

- 画布：头像 64×64 或 48×48（系统给模板）；身体帧 48×64；全部透明底 PNG
- 颜色：尽量贴 master palette，偏一点没关系（实时滤镜统一收口），不要自己调色阶/滤镜
- 动作帧：系统给模板工程文件（Aseprite .ase），在模板图层上画
- 不需要管命名、路径、格式转换、部署——全部系统自动

## 岗位画像（2026-08-09 讨论）

要找的是**会画像素画、有技术 sense 的人**（2D TA / 会脚本的像素美术），不是传统 TA——
本项目的渲染管线是代码（AI 负责）、3D 场景是场景组、生成管线在 Art Lab，
传统 TA 的主战场（引擎 shader graph / rigging / DCC 工具链）在这里基本不存在。
真正缺的 20 分：像素审美终审、master palette 拍板、情绪小动作手绘关键帧、场景概念图。

- 筛选顺序：像素画作品集（硬门槛）→ 会不会写小工具（加分项，非门槛）
- 招聘文案写"像素美术（技术美术方向优先）"，不要写"技术美术"
  （后者容易引来只会 Unity shader graph 的候选人）
- **专家模式**：对有能力的候选人，Art Lab 额外暴露滤镜参数（抖动/描边/palette 距离函数）、
  Blender 风格化脚本入口、Aseprite 导出 lua——以配置/脚本接口形式开放，仍不碰主仓库代码

## 分期

- **v1（随 2.5.E.1 切片）**：人物馆（生成/策展/下载/上传/采用）+ 动效台基础 + 世界截图预览
- **v2**：调色板室编辑 + 审核流状态机 + 道具贴片
- **v3**：批注协作、版本对比、批量审核

# 仓库外消费者：三人的周末散步

这个脚本只导入安装后的 `meetmind_core` 和 Python 标准库；不导入旧示例、后端配置或演示 fixture。
在已安装内核的环境中运行：

```bash
python weekend_walk.py --output ./walk-output
```

输入完全为脚本里的合成人物与记录。它顺序执行：
1. 三人各自认领；未确认候选仅观察者可见。
2. 一人明确提交日历经历（仍是单方自报），生成带语义的小径和纪念标记。
3. 只改标记颜色，保留小径部件和参与关系。
4. 三人分别接受、拒绝、尚未决定；仅接受者生成个人日历文件。
5. 接受者自报结果，再带进一次新签到；不推断其他人参加或完成。
6. 撤回本人的结果与原经历，保持独立后续经历、重新加载日志并核对投影。

输出 `events.json`（完整可信测试日志）、`stages.json`（各阶段、各查看者投影）、
`lin-next-walk.ics`（接受时导出的个人计划，后续事件不会改写已经导出的文件）。
这些是开发者诊断产物，包含各人的视图，不应整体公开给一个真实用户。
脚本不发送消息、不抓取日历、不调用模型、不提供新的浏览器界面。

仓库根目录执行 `python scripts/verify-core-package.py`，可复现独立 wheel 安装与仓库外运行。
当前已有 Three.js 渲染消费者继续使用兼容入口；本例验证不同人数和业务数据的接入，不代表户外场景产品上线。

# Echo Campus · 让活动的相遇继续发生

一座可以浏览、走近和留下连接的数字园区，为线下活动提供一个共同的线上空间。

**体验入口：<https://capture.meetmind.online/echo-campus/>**

## 一次轻触，进入同一个世界

来宾通过手机入口填写愿意公开的昵称、身份、供给与需求，领取一个风格化分身。分身出现在现场大屏的园区中，让抽象的参会名单成为可以点选和认识的人。

来宾可以查看名片，发现供需相关的伙伴，并发起一次相遇。只有对方确认后，两个人之间的连接才会在共同的世界里点亮。

手机操作，大屏同步。活动结束后，已经确认的相遇仍可作为后续联系的入口。

## 建议现场演示：3 分钟

| 时间 | 来宾看到什么 |
| --- | --- |
| 0:00–0:40 | 从白色建筑、水庭和连廊开始，展示全景与入口镜头 |
| 0:40–1:20 | 手机扫码填写名片，分身出现在园区 |
| 1:20–2:10 | 点选人物，查看供需推荐及每条推荐的理由 |
| 2:10–2:40 | 第二部手机加入，双方确认相遇，大屏点亮连接 |
| 2:40–3:00 | 切换为水上艺廊，展示同一活动在不同空间中的表达 |

当前提供「白庭校园」与「水上艺廊」两套视觉方向。建筑风格、活动主题、园区名称、入口文案和人物配色可围绕合作方定制，也可以接入新的 3D 场景。

## 对活动的价值

- **让第一印象更鲜明。** 用一座完整的空间承接活动主题，形成可以传播的画面与共同记忆。
- **让认识人更有依据。** 来宾主动表达能提供什么、希望认识谁，推荐理由清楚可见。
- **让线下参与得到即时回应。** 入场与确认相遇能在大屏被看见，适合小组活动、创始人交流和共创聚会。
- **让活动资产继续复用。** 同一套体验可以换园区、换视觉、换活动资料，为下一场活动延续使用。

## 可共同定制的内容

| 方向 | 可讨论内容 |
| --- | --- |
| 活动视觉 | 品牌色、园区入口、活动名、建筑和景观风格 |
| 参与方式 | 手机二维码、NFC 标签入口、大屏与主持人口播流程 |
| 来宾名片 | 角色、兴趣、供给、需求和公开展示范围 |
| 相遇机制 | 认识伙伴、双向确认、活动后的联系承接 |
| 场景资产 | 自建白色建筑、定制园区或经授权的生成式空间 |
| 现场组织 | 分组体验、引导员流程、网络与设备配置 |

## 试点范围与活动前准备

建议先以一场可控人数的现场试点确认体验，再根据人数、场地网络和组织方式扩展。

本演示中的内置人物与关系均为虚构资料。新领取的分身是风格化形象，不代表已经完成真人外貌重建；当前推荐来自双方公开填写的供需标签，理由可以核对。

NFC 可承载同一个入场网页链接。正式活动前，需要共同确认卡片与手机实机表现、私密领取凭据、现场网络、大屏设备、公开资料范围及参与人数。当前线上原型已完成真实浏览器桌面与移动尺寸画面检查、双隔离会话的领取与相遇确认，并验证切换场景后身份和关系保留。实体 NFC、实际手机性能及现场网络仍需联调；移动尺寸视口检查不能替代实体手机测试。

**希望共同验证的问题很简单：能否让来宾更愿意认识彼此，并把有价值的相遇留在活动之后。**

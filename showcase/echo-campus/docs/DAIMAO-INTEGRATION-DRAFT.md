# 相遇之庭 × 呆猫小镇：成员数据接入说明（草案 v0.1）

2026-10-09 · 待 10-10 会上确认后定稿

呆猫小镇的成员以分身出现在相遇之庭的校园地图上，和现场来宾同屏。呆猫这边只需要提供一个只读接口，我们的服务端每分钟读一次，不需要实时推送。

## 1. 展示规则

- **现场来宾优先**：到场来宾优先显示，刚到场 3 分钟内的排在最前；剩下的名额给呆猫成员。
- **轮换**：呆猫成员每 10 分钟换一批。同一时刻，所有手机、电脑和大屏看到的是同一批人；最近活跃（`active: true`）的成员优先进入每一批。
- **同屏上限**：大屏和电脑 50 人，手机 30 人（已实测 60 人同屏）。后台一场活动可存 1200 人，可以再调。
- **名片**：点开呆猫成员能看到昵称、身份、机构、一句话介绍、「我能提供 / 我在寻找」，带「呆猫小镇」来源标记；不显示任何联系方式。
- **互动**：呆猫成员不参与现场的「碰一下」和「双方确认」。本人到场后是否合并成同一个人，见第 6 节。

## 2. 接入方式

推荐由我们来读：

- 呆猫提供一个 HTTPS 只读接口，例如 `GET https://<呆猫域名>/<路径>`。
- 我们的服务端每 60 秒请求一次，每次取本场要展示的全部成员（第一版用全量，不做增量）。
- 鉴权：请求头 `Authorization: Bearer <token>`。token 由呆猫生成后交给我们，只保存在我们的服务端，不会出现在浏览器里。
- 返回 `{ "members": [...], "nextCursor": "..." }`，也可以直接返回数组。有下一页时给出 `nextCursor`，我们会带 `?cursor=<nextCursor>` 再取一页；最多 10 页、2000 人。
- 每次请求 5 秒超时；读取失败时继续使用上一次的名单，地图不受影响。

如果呆猫更方便主动推送，也可以每分钟把全量 POST 到我们提供的地址（带签名），两种方式二选一。

## 3. 字段

| 字段 | 必填 | 类型 / 长度 | 说明 |
| --- | --- | --- | --- |
| `id` | 是 | 字符串（字母、数字、`_`、`-`，≤ 64）或整数 | 成员在呆猫的稳定 ID。不要用手机号，可以是哈希 |
| `nickname` | 是 | ≤ 24 字 | 地图上显示的名字（字段名也可以是 `name`） |
| `role` | 否 | ≤ 60 字 | 身份，如「独立开发者」「投资人」 |
| `organization` | 否 | ≤ 80 字 | 机构或项目名 |
| `bio` | 否 | ≤ 160 字 | 一句话介绍 |
| `offer` | 否 | ≤ 160 字 | 我能提供 |
| `need` | 否 | ≤ 160 字 | 我在寻找 |
| `category` | 否 | 枚举 | 参会类别，取值与本场活动的类别表一致（如 `founder`、`investor`、`guest`），决定名牌颜色；不填按 `guest` |
| `avatar` | 否 | 字符串 | 指定我们 12 款分身之一（如 `shanhu`），或一个主色 `#RRGGBB`；其余情况按 `id` 固定分配一款分身 |
| `active` | 否 | 布尔 | 最近是否活跃，轮换时优先 |
| `updatedAt` | 否 | ISO 8601 | 资料最后更新时间（第一版不使用，可以先传） |
| `consent` | 是 | 布尔 | 本人已同意在本场活动公开展示以上资料。只传 `true` 的成员 |

请不要传：手机号、微信号、邮箱、真实姓名、证件信息、头像原图。

## 4. 返回示例

```json
{
  "members": [
    {
      "id": "dm_7f3a9c",
      "nickname": "小李",
      "role": "独立开发者",
      "organization": "一人公司 · 记账工具",
      "bio": "做了三年独立开发",
      "need": "找增长合伙人",
      "category": "founder",
      "avatar": "#c96f4a",
      "active": true,
      "updatedAt": "2026-10-09T20:30:00+08:00",
      "consent": true
    }
  ],
  "nextCursor": null
}
```

## 5. 我们这边会做什么

- 每分钟读取、按 `id` 去重，超长的字段按上表长度截断，去掉尖括号和控制字符；表外的字段一律丢弃，不会存下来。
- 呆猫成员在相遇之庭里的编号是 `daimao-<呆猫 id>`，和现场来宾互不冲突；形象和地图上的站位都由 `id` 决定，每块屏幕上一致。
- 内容只做截断和清洗，不做审核；不合适的昵称和介绍请在呆猫这一侧过滤后再给。
- 活动结束后，按活动方约定的期限删除这批数据。

## 6. 会上需要确认

1. 由我们读，还是呆猫推（第 2 节）。
2. 呆猫成员到场后，是否要和他在现场领取的分身合并成同一个人；如果要，需要一个双方都能对上的字段，比如活动报名号。
3. 本场活动的参会类别表：类别 id、名称和颜色，最多 12 种，与手环颜色一致。
4. 呆猫测试接口的地址、token 和联调时间。
5. AI 公屏聊天：第一版不做。以后要做，也只播放提前生成、经活动方审核过的内容，不由用户触发。

## 7. 时间

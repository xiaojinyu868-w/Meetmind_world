# 碰一碰物料：技术要求（草案）

2026-10-09 · 样式和数量由活动方拍板；这份只写技术上必须满足的条件，照着下单就能用。

## 1. 三类物料

| 物料 | 给谁 / 放哪 | 芯片里写的链接 | 数量建议 |
| --- | --- | --- | --- |
| 手环或胸卡 | 每位来宾，按参会类别分色 | `https://capture.meetmind.online/echo-campus/?entry=nfc&tag=WB-<类别>-<编号>` | 预计到场人数 × 1.15（补发、损坏） |
| 打卡点立牌 | 每个合作方或展位一个 | `https://capture.meetmind.online/echo-campus/?tag=CP-<点位>` | 点位数 + 2–3 个备用 |
| 入口立牌 | 每个入口 | `https://capture.meetmind.online/echo-campus/?entry=nfc&tag=GATE-<入口>` | 每个入口 2 个 |

另备约 20 张空白标签，现场补写。参会类别最多 12 种，打卡点最多 24 个。

## 2. 芯片与印刷

- **芯片**：普通 NFC 标签 NTAG213 就够。链接约 75 个字符，NTAG213 能存 144 字节。iPhone XS 及以上亮屏贴近即可打开，安卓需要先打开 NFC。
- **二维码**：每件物料同时印同一个链接的二维码，边长不小于 2 cm。没开 NFC、碰不出来的手机扫码进入。
- **标识**：在芯片位置印「碰这里」，并印上物料编号，方便补发和排查。
- **颜色**：手环颜色和参会类别一一对应，请在定样式时一起定类别表（类别 id、名称、颜色）。
- **金属表面**：立牌如果贴在金属上，要用抗金属标签，否则读不出来。

## 3. 写入流程

数量和类别定下后，我们当天生成编码清单（每行一个编号和对应的唯一链接，Excel 可直接打开）：

```bash
node scripts/nfc-tags.mjs --config <活动配置> --wristbands investor:40,founder:120,guest:60 \
  --checkpoints welcome,stage,roadshow --gates south --spare 0.15 --out nfc-tags.csv
```

脚本会核对类别和点位都在活动配置里（拼错直接报错，不会把错的发给厂家），按备用比例向上取整加量，并检查最长的链接放得进 NTAG213。厂家按清单写入芯片、印二维码和编号。收货后抽查 10 件，用 iPhone 和安卓各碰一次。

## 4. 两个需要先知道的限制

- **支付宝「碰一下」**：如果物料要走支付宝的碰一下，需要支付宝侧的配置和联调，目前还没开始。明天就要下单的话，建议先用普通 NFC 标签，两者可以并存。
- **防复制**：普通 NFC 标签里是固定链接，可以被复制或转发，适合社群活动。服务端用 `taps: "open"` 接受这类未签名的触碰（记为未认证）。如果要求每次触碰都带一次性签名、防止复制，芯片要换成 NTAG 424 DNA，单价更高，我们这边还需要 1–2 天做验签适配。

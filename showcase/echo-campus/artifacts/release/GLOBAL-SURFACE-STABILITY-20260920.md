# Echo Campus 整园表面稳定性修复

本次处理完整园区模型内的重复覆盖、深度精度与阴影/细纹采样，替代上一版按材质名称逐处设置深度优先级的补丁。2026-09-21 已发布，见文末核验。

## 问题与改动

建筑工程模型同时包含完全共面的重复表面、相隔约 1–3 mm 的近共面层、部分相交覆盖与压缩造成的零面积面。改变镜头时，它们竞争深度缓冲，产生斑点、条带和大片闪面。只调整屋顶或展板的材质偏置不能消除这些几何原因。

1. 对整园任意朝向的表面执行覆盖清理。仅减去已保留面的实际覆盖，独占多边形重新三角化；源名称、材质和工程坐标保留。先全空间扫描，再用精确三角对应关系检查修改面与整个园区的邻域，避免只复看截图标记的部位。
2. 使用通过实际设备检测的反向深度和 DEPTH_COMPONENT32F 附件，保留近景人物。设备不支持时使用常规深度与保守包围盒裁剪范围。白庭、艺廊及 SPZ 保留其兼容渲染路径，换场景时保留选择与本地文件。
3. 阴影使用固定 PCF 采样方向，修正 Three r185 反向深度的偏置符号；玻璃细纹按像素覆盖范围过滤。展板仍有真实面间距、正常深度遮挡和点击功能。园区远方地面淡出，消除远裁剪造成的硬直线。
4. 采用无新增量化的 Meshopt 压缩并验证位置、法线和有向三角形读回一致性。服务端直接发送离线 `.glb.gz`，无需实时压缩；模型 URL 带内容哈希，刷新不会继续命中旧 GLB。

## 几何证据与边界

原发布 GLB SHA-256：`78bbf162e6a3ce8ac17294bf1ca649976cbba536687f90e7598ce4c8c4ee4092`。五个工程来源为 T1–3、T6、HUB、C 商业地块和连廊；逐来源轴对齐边界差异为 0。

扫描范围为对称面距不超过 3 mm、无向法线点积至少 .99995、主轴投影覆盖面积大于 1 cm²。两次完整 R-tree 扫描不使用清理时的平面分桶；后续以 float32 三角位置逐字节、多重集对应证明未改区域，所有修改面与保留残余端点重新查询全空间索引。

浮点重建不是数学无限精度：保留了同材质、同平面、同插值法线的微米宽边界细片，详细尺寸与例外在 `public/scenes/venue/venue-campus.surface-stability.audit.json`。不为了让统计数字归零而平移建筑或删除独占轮廓。压缩的“无损”只指清理后几何到交付文件，不代表原工程逐面无变化。

最终资产与各轮审计见上述 JSON；旧 `venue-campus.assembly.audit.json` 与 `.compression.audit.json` 保留作初始组合/旧 Draco 版本的历史来源。公开 GLB 不含原始 SKP/3DM。

# 完整园区模型 · 内部发布来源说明

日期：2026-09-20。范围：本轮由用户提供的模型组合完整园区，供内部追溯与验收。浏览器效果和部署验收由主发布报告另行记录。

## 本轮纠正

原先前端分别预览 T6 主楼、T1–3 塔楼与 C 商业区，导致合作方只看到部分园区。本轮从用户原始文件恢复共同工程坐标，组合三座塔楼、T6 主楼、HUB 中庭、C 商业裙房及高塔、统一连廊和一份道路总图。

原始 AB 包的 7 个 SKP，以及 C 包的 2 个 SKP、1 个 3DM，均已从 ZIP 重新核对 SHA256，与解压文件及转换来源记录一致。没有用生成建筑替换真实主体。

## 坐标和版本排除依据

- 原始 SDK 转换将英寸 Z-up 换算为米制 Y-up，保留工程实例变换。整套模型统一减去 `[102.68817138671875, 0, -21.1610107421875]` 作为浏览器坐标原点，没有分别把楼群移到中心后再猜位置。
- 雨棚与 C05-18 有 132,010 个相同工程坐标的量化三角形，且大部分位于高程约 8–19 米的连廊。因此使用一版连廊并去除重复面，避免不同版本重叠造成闪烁。
- 雨棚文件隐藏的 `opt1/opt2/opt3/opt5` 是旧塔楼方案，保持隐藏；塔楼采用独立 20231226 文件。
- C05-04 的 98.19% 比较三角形已经存在于 C05-18；C05-18还包含完整高塔，故不叠加旧版。Rhino 裙房是另一方案，当前可见几何高度约53.4米，不与所选商业区重叠加载。
- 独立 `ufo.skp` 已与 HUB 大量重合。独立楼梯位于另一处局部坐标，T6 吊顶文件地面高程71.1198米且整体现置位置不同；二者缺少可证实的装配变换，不作为新增建筑随意摆放。

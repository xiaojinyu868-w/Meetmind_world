# Geometry and offline visual evidence

The authoritative procedural source is `src/scenes/CampusScene.js`, `SceneKit.js`, and `Characters.js`.

These images are **Blender architectural reference renders, not browser screenshots and not WebGL performance evidence**. Their geometry is exported from the actual Three.js scene factories. Canvas textures are generated by the same source with `@napi-rs/canvas` and exported into PNGs. Blender adapts transparent glazing and water shading; those renderer differences must remain disclosed. Avatars in architectural references use bind poses. Actual browser motion and performance still require separate runtime verification.

## Construction measurements (2026-09-16)

Pure Three.js construction, using high foliage quality:
- Whitewater Courtyard: 24 scene meshes, 444858 scene triangles.
- Water Gallery: 20 scene meshes, 335256 scene triangles.
- Characters: 2714-2762 triangles each, one SkinnedMesh and one material per avatar.
- Each scene supplies 24 placement anchors, independent materials/geometries, cameras, bounds, collision circles, and isWalkable(x,z).
- Both scene bridge centers are walkable; sample water point (5,0) is not.
- Foot IK sampled over 8 seconds: resting/stance joint y about 0.085 m, max swing y about 0.245 m.

Counts above exclude repeated render passes and are **not** renderer.info metrics. Planar reflections and shadows will increase submitted triangles. No WebGL claims follow from these counts.

## Reproduce

`node artifacts/geometry/export-scenes.mjs`

The exporter currently resolves software canvas at `/tmp/node_modules/@napi-rs/canvas` installed only for authoring; install or adjust this location on another workstation. It creates full geometry JSON including UV/normals/vertex colors and instancing matrices/colors, with Canvas PNG maps. The JSONs are large authoring intermediates and should not ship in the web bundle.

`blender -b --threads 8 --python artifacts/geometry/render-reference.py -- artifacts/geometry/campus.json artifacts/geometry/campus-hero-textured-reference.png 1920 1080 24 hero`

Camera names are hero, arrival, garden, aerial, lobby. Use gallery.json for the second scene. `export-portraits.mjs` exports the two runtime avatars.
